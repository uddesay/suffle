# 📜 Suffle


**▶ Play live: https://uddesay.github.io/suffle/**
Confused about what to do? Suffle turns indecision into a tiny game:

1. **Confusion** – tell the game your dilemma.
2. **Options** – write 3–5 choices; each becomes a paper chit.
3. **Shuffle** – the chits are folded, tossed around and re-dealt so you can't track any of them.
4. **Pick** – tap any one chit.
5. **Follow it** – the chit unfolds, and whatever is written on it is your decision.

Plain HTML/CSS/JS, no build step. Open `index.html` in a browser.
